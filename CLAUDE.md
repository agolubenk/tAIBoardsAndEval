# CLAUDE.md — aiBoards & eval repo map

Самостоятельный продукт-слой: доски (boards), измерения и демоны (eval), командные процессы (process + `.claude`/`.continue`/`.agents`/`.ai`). Живой инстанс слоя сегодня работает над HR_Helper-v2; здесь — канонический дом. Как развернуть слой над другим проектом — [`process/README.md`](process/README.md).

## Parts

- `boards/` — **aiBoards**: kanban для людей и ИИ-агентов. pnpm workspace (vite-plus), форк Kaneo (MIT). Свой `CLAUDE.md`/`AGENTS.md` внутри.
- `eval/` — **eval**: python-stdlib пайплайн команды (Нерв, swarm, капсулы, геномы, `tools/spawn_session.sh`).
- `process/` — **слой**: пусковые промпты команды (`SUCCESSOR-PROMPT*`), операционная модель инстанса (`model/`), гайд развёртывания.
- `.claude/` — функциональный слой: `rules/` (законы, грузятся по `paths:`), `agents/`, `hooks/` (+тесты), `scripts/`, `skills/` (канон), `memory/` (чанки + `capital.json`), `settings.json`.
- `.continue/`, `.agents/` — зеркала слоя для других харнессов; регенерирует `.claude/scripts/sync-agent-skills.sh`.
- `.ai/` — процесс папок задач (`templates/`, живые дела `task/`).

## Commands

boards (inside `boards/`):

```bash
pnpm install --frozen-lockfile
pnpm lint && pnpm typecheck && pnpm test && pnpm build
pnpm i18n:check && pnpm openapi:check
pnpm dev                                   # from-source dev
docker compose -f compose.local.yml up     # local stack (needs .env.local)
```

eval и слой (from repo root, Python ≥ 3.10, stdlib only):

```bash
python3 -I -m unittest discover -s eval/nerve    -p 'test_*.py'
python3 -I -m unittest discover -s eval/pipeline -p 'test_*.py'
python3 -I -m unittest discover -s eval/swarm    -p 'test_*.py'
for t in .claude/hooks/test_*.py .claude/scripts/test_*.py; do python3 "$t"; done
```

## CI

- `.github/workflows/boards-ci.yml` — lint / typecheck / unit / build / i18n / openapi on `boards/**`
- `.github/workflows/eval-ci.yml` — unittest on `eval/**`
- `.github/workflows/layer-ci.yml` — hook/script tests on `.claude/**`, `eval/tools/**`

## Rules of the road

- Runtime state is never committed: `eval/nerve/state/`, `eval/swarm/state/`, `.claude/memory/session/`, `.claude/settings.local.json`, `CLAUDE.local.md`, `.env*`, `.secrets/`, `node_modules`, build outputs.
- Skills are edited only in `.claude/skills/` (canonical); mirrors are regenerated by `sync-agent-skills.sh` — never edited by hand.
- eval stays stdlib-only python; adding a dependency is a decision, not an accident.
- Instance paths live in exactly two places — `.claude/rules/*` (`paths:` sections) and `eval/nerve/config.json`; when adapting the layer to a host project, change only those.
- DB migrations (`boards/apps/api/drizzle/`) and deploy steps are owner-approved changes.
- PR checks green (boards / eval / layer, by touched paths) before merge to `board-agents`.
