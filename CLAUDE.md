# CLAUDE.md — tAIBE repo map (tasks · AI Boards · Eval pipelines)

Самостоятельный продукт-слой: доски (boards), измерения и демоны (eval), сервисы контроля и ИИ-контура (infra), командные процессы (process + `.claude`/`.continue`/`.agents`/`.windsurf`/`.ai` + `docs`). Живой инстанс слоя работает над host-проектом-инкубатором; здесь — канонический дом. Откуда что перенесено — [`process/TRANSFER.md`](process/TRANSFER.md). Как развернуть слой над другим проектом — [`process/README.md`](process/README.md).

## Parts

- `boards/` — **aiBoards**: kanban для людей и ИИ-агентов. pnpm workspace (vite-plus), форк Kaneo (MIT). Свой `CLAUDE.md`/`AGENTS.md` внутри.
- `eval/` — **eval**: python-stdlib пайплайн команды (Нерв, swarm, капсулы, геномы, `tools/spawn_session.sh`); `evolve/` — версии слоя, бюджет L1 по ролям, дубли, A/B версий (`eval/evolve/README.md`).
- `process/` — **слой**: пусковые промпты команды (`SUCCESSOR-PROMPT*`), операционная модель инстанса (`model/`), гайд развёртывания.
- `.claude/` — функциональный слой: `rules/` (законы, грузятся по `paths:`), `agents/`, `hooks/` (+тесты), `scripts/`, `skills/` (канон), `memory/` (чанки + `capital.json`), `settings.json`.
- `infra/` — сервисы процесса: ИИ-консилиум, очередь владельца (MCP `oq_*`, бот, ops-консоль), MCP-хаб, llm-gateway, headroom, скрипты ИИ-контура. Роль — `infra/CLAUDE.md`.
- `docs/` — сквозные спеки (очередь владельца, консилиум), журнал закрытого `docs/plans/DONE.md` + `done/`, заметки ИИ. Карта — `docs/README.md`.
- `.continue/`, `.agents/`, `.windsurf/skills/` — зеркала скиллов для других харнессов; регенерирует `.claude/scripts/sync-agent-skills.sh`.
- `.ai/` — процесс папок задач (`templates/`; живые дела `task/` — рантайм, в `.gitignore`).
- `worktrees/` — параллельные checkout'ы `<track>/<topic>` (`make wt-help`, правило `.claude/rules/07-worktrees.md`).

## Commands

boards (inside `boards/`):

```bash
pnpm install --frozen-lockfile
pnpm lint && pnpm typecheck && pnpm test && pnpm build
pnpm i18n:check && pnpm openapi:check
pnpm dev                                   # from-source dev
docker compose -f compose.local.yml up     # local stack (needs .env.local)
```

eval и слой (from repo root, Python ≥ 3.10, stdlib only):

```bash
python3 -I -m unittest discover -s eval/nerve    -p 'test_*.py'
python3 -I -m unittest discover -s eval/pipeline -p 'test_*.py'
python3 -I -m unittest discover -s eval/swarm    -p 'test_*.py'
for t in .claude/hooks/test_*.py .claude/scripts/test_*.py; do python3 "$t"; done
```

Всё разом — `make check` (eval + слой + infra); доски — `make check-boards`. infra (from repo root):

```bash
node --test infra/owner-queue-mcp/test/*.test.mjs infra/llm-gateway/test/*.test.mjs
(cd infra/owner-queue-bot && node --test test/*.test.mjs)
(cd infra/ai-council && python3 selftest.py)      # pip install -r infra/ai-council/requirements.txt (mcp<2)
(cd infra/ops-console && npm ci && npm run typecheck && npm test)
python3 infra/scripts/misc/done-index.py --check
```

## CI

- `.github/workflows/boards-ci.yml` — lint / typecheck / unit / build / i18n / openapi on `boards/**`
- `.github/workflows/eval-ci.yml` — unittest on `eval/**`
- `.github/workflows/infra-ci.yml` — owner queue, llm-gateway, ai-council, ops-console, closed-items index on `infra/**`, `docs/plans/**`
- `.github/workflows/layer-ci.yml` — hook/script tests and layer versions (`eval/evolve/catalog.py --check`) on `.claude/**`, `eval/tools/**`, `eval/evolve/**`, prompts, role cards

## Rules of the road

- Runtime state is never committed: `eval/nerve/state/`, `eval/swarm/state/`, `.ai/task/`, `.claude/memory/session/`, `.claude/council/`, `.claude/settings.local.json`, `CLAUDE.local.md`, `*.db`, `.env*`, `.secrets/`, `node_modules`, build outputs.
- Ask the owner once: before a question — `python3 -I eval/tools/ask_once.py check "…"` (3 — decided, 4 — already asked); after — `record`. Layer versions (`eval/evolve/catalog.lock.json`, `history.jsonl`) are written by the Stop hook and committed with the change.
- Skills are edited only in `.claude/skills/` (canonical); mirrors are regenerated by `sync-agent-skills.sh` — never edited by hand.
- eval stays stdlib-only python; adding a dependency is a decision, not an accident.
- Instance paths live in exactly two places — `.claude/rules/*` (`paths:` sections) and `eval/nerve/config.json` (`repo_root`, `product_tree`, roles, queue); role genomes `eval/pipeline/genome/*.json` are rendered from it by `build.py` (`--check` in CI). When adapting the layer to a host project, change only those and re-render.
- DB migrations (`boards/apps/api/drizzle/`, `infra/ops-console/server/db/`) and deploy steps are owner-approved changes.
- Closing an item = card status on the board **and** a one-line entry in `docs/plans/done/<module>.md` (format — `docs/plans/DONE.md`).
- External solutions are adopted only to strengthen and complement the product (measured before/after), never to replace a part or leave it at the same level; analysis lives in `docs/integrations/`. Whatever core, capability, design or principle is taken is credited in the tool's review, in the docs of the part it went into and in the root `README.md` (Origins).
- PR checks green (boards / eval / layer, by touched paths) before merge to `board-agents`.
