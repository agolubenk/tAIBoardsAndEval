# Рой — рутинная выжимка не на Opus (П9)

Решение владельца **d-pipe-swarm = «free-code»** (28.10): Haiku и бесплатные внешние модели, **в том числе код без
секретов**. Основание экономии — хвосты `результат:Bash` $93.5 и `Read` $20.7 в Т2 (`pipeline/PIPELINE.md` П9).

## Порядок выбора (кто делает выжимку)

1. **Haiku 5.5 субагентом** — та же подписка, нового получателя данных нет. Без установки чего-либо:
   `Agent(subagent_type: "log-triager", model: "haiku", prompt: …)` для длинного лога,
   `Agent(subagent_type: "Explore", model: "haiku", …)` для поиска по коду. По одному, не веером
   (память `feedback_agent_fanout_cost`). Ответ — со ссылками `file:line`, Claude выборочно сверяет 1–2.
2. **Бесплатные внешние модели** — `swarm.py` через llm-gateway (`127.0.0.1:8789`, пул `free`), когда в шлюзе есть
   ключи OpenRouter. Без ключей шлюз уходит в локальную Ollama — проверено 28.10: `kimi-vl:24k` за 73 с, 34 ссылки
   из 34 битые. Локальный запасной путь для выжимки **непригоден**, рой его сам помечает «ПРОВЕРЬ ВЫЖИМКУ».
3. **Сам Claude** — когда выжимка спорная, данные с PII/секретами или ссылки битые.

**На 28.10 16:20:** шлюз жив, `keys: 0`. Пока владелец не добавит ключи OpenRouter (`OPENROUTER_KEY_1…` в
`infra/llm-gateway/.env`, файл читает только владелец), рабочий путь роя — п. 1 (Haiku).

## Что уходит наружу (egress.py)

- **Не отправляются файлы**: `.env*`, `*.pem|key|p12|pfx|kdbx|jks`, `id_rsa*`, дампы `*.sql|dump|bak|sqlite|db`,
  `~/.ssh`, `~/.aws`, `~/.claude-mem`, `secrets/`, `credentials*`, `.state/`, `.mcp.json`, `settings.local.json`,
  `.npmrc`, `.netrc`, `*.tfstate`.
- **Маскируются в тексте** (по месту, имя переменной остаётся): приватные ключи, JWT, `sk-…`, `ghp_…`, `github_pat_…`,
  `xox?-…`, `AKIA…`, `AIza…`, `gw-…`, `ntn_…`, токены Telegram-ботов, `Bearer/Basic …`, пароль в URL,
  присваивания `*password|secret|token|api_key…= значение`, e-mail, телефоны с `+`.
- Ссылки на env (`process.env.X`), аннотации типов (`password: string`), даты, SHA и id — не трогаются.
- PII в рабочих данных HR (кандидаты) рой не получает вообще: только код, логи, диффы.

## Команды

```bash
S=eval/swarm
python3 -I $S/swarm.py ask "почему упал гейт" путь/к/логу.txt           # файлы — с номерами строк
npm run test 2>&1 | python3 -I $S/swarm.py ask "первая причина падения" -  # stdin
python3 -I $S/swarm.py ask "…" файл --dry-run                            # что уйдёт наружу, без отправки
python3 -I -m unittest discover -s $S -p 'test_*.py'
```

stderr — одна строка: модель, секунды, сколько символов ушло, что замаскировано, «ссылок N, битых K». Битые ссылки
или ноль ссылок → «ПРОВЕРЬ ВЫЖИМКУ»: такую выжимку не использовать без сверки. Вызовы идут строго по одному
(`state/swarm.lock`): шлюз может уйти в локальную модель, а локальные модели запускаются только последовательно.
Токен шлюза читается из файла (`infra/llm-gateway/.state/token`, переопределение — `SWARM_GW_TOKEN_FILE`), в
argv/лог не попадает.
