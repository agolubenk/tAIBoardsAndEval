## Ловушки (из отчётов d9 и 85)

- `delete_branch_on_merge=false`: GitHub сам не перенацелит #444.
- `--match-head-commit` проверяет голову, а не базу.
- В очереди деплоя ждёт только один прогон. Пробу делать по голове main. Перед «деплой свободен» — `gh run list`.
- Новая голова → линзы заново; sha в m-пункт — только после всех линз. Перед вердиктом сверить голову:
  `gh pr view N --json headRefOid`.
- `reset --keep` молча удаляет и перезаписывает файлы, которые main снял с учёта или которые игнорируются. Копировать
  до reset; `--hard` для checkout владельца нельзя.
- Токены шлюза и OQ не печатать — сверять по sha256. Содержимое секретов не читать: классификатор блокирует.
  Проверять по git-метаданным (blob id, `--find-object`, `check-ignore`).
- В trial-папке собрать types до tsc: dist бывает старым. Пробы — на `git archive <голова>` + симлинки
  `node_modules` и `tsconfig*.json`.
- GH Actions выключен биллингом, `ci-frontend` на main красный (madge) — гейты локально, твой вердикт единственный.
- `postgres-readonly` закрыт для rbac-таблиц: любая цифра с прода — отдельный s-пункт.
