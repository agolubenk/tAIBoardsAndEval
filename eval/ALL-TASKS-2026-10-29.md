## 7. Банк идей — не начато или отложено

**Пайплайн:**

- **Антиген «длинный вывод Bash».** В Б4 результаты Bash — самая крупная статья: 836 вызовов, хвост 12.8M — в 1.5 раза
  больше списка скиллов. Урок вставляется, когда команда без `tail`/`grep`/файла в scratchpad может дать много
  строк.
- **Хуки входа** (≈ 1% Т3, до ≈ $10 на дне Т2):
  - DAMS-вставки только на сообщение человека;
  - пропуск сообщений агентов, уведомлений и мониторов в `UserPromptSubmit`;
  - дедуп повторных вставок.

  Это правка `.claude/scripts` — PR с `[skip ci]`, нужен ваш вопрос-ответ.
- **Стигмергия и кворум для всей команды:** статусы в PR и `work_state`, сообщения только «нервные» (прод НЕ ОК,
  стоп, назначение, d-ответ). Сейчас это пилот одной роли по d2. Для всех ролей нужна правка правил 2 и 3 TEAM-0.
- **Автоматический `work_state`.** Механику (ветка, голова, pid) пишет хук PostToolUse, а не ход модели. В Т2 было
  661 вызов `work_state` (9.6% вызовов).
- **Ночная консолидация** на локальной Ollama или Haiku, строго по одной модели: из транскриптов дня — капсулы,

## 9. Правила, которые действуют для всего этого

- Вливаете только вы — кнопкой «Влить» у m-пункта. Push в main с не-md изменениями — сразу деплой прод.
- Команды на VPS и DNS — только s-пунктами: одна строка base64 → bash, откат в `after`.
- `ADMIN_DOMAIN` — только после #365 и при вас. Переадресации — только 302. Сертификат d4dev руками не выпускать.
- Больше двух агентов или любой workflow — только по вашему «да» с ценой. Ollama — строго по одной модели. Консилиум
  можно без разрешения.
- Пункты `s-tb-*`, `c-tb-*` и `c-pipe-pilot-launch` принадлежат сессии t-boards-claude — их не дублировать.
- Staged-переименования в `t-boards/` основной папки не откатывать.
- Форк kaneo не пушить в upstream.
- Notion — только чтение без явного «да». Из продукта не писать в claude-mem и Notion.
- Секреты:
  - только `*_FILE`;
  - `.env` не читать;
  - токен очереди — через stdin, не печатать.
- Время — только из `date` в том же вызове.
- Для supertick-eval и t-boards адверсариальная проверка отменена вашими словами («заканчивай всё без
  адверсариальности»). Для PR в основной репозиторий и для плана перехода она остаётся (≥ 3 и ≥ 4 участника).
- «Не тратим токены впустую».
