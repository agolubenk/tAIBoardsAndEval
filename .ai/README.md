# `.ai/task/<TASK-ID>/` — папка дела задачи

Рабочая единица длинной задачи — не чат, а эта папка. Причина простая: Continue (и любой
IDE-агент) — интерфейс и исполнитель, а не оркестратор. Он не гарантирует, что три мнения
в одном чате независимы, не хранит доказательную базу как отдельный артефакт и не знает,
что попытка действительно провалилась. Файлы знают.

Локальные модели не ведут бесконечный разговор: каждая роль обновляет ОДИН конкретный
артефакт, ссылается на факты из репозитория и передаёт работу следующей.

## Состав

| Файл | Кто пишет | Что внутри |
|---|---|---|
| `brief.md` | `/task-brief` (Qwen Architect локально) | GOAL, CONTEXT, NON-GOALS, CONSTRAINTS, ACCEPTANCE CRITERIA, RISKS, OPEN QUESTIONS |
| `recon.md` | `/local-recon` (Qwen Architect, read-only) | Карта кода, подтверждённые факты `файл:строка`, 2–4 гипотезы + способ опровержения каждой |
| `hypotheses.md` | `/glm-second-opinion` (GLM4 Local, read-only) | Ложные допущения, пропущенные зависимости, контрпримеры, тест против текущего плана |
| `plan.md` | человек или Architect | Выбранный план и инварианты |
| `evidence.md` | `/execute-evidence` (Qwen Coder) | Команды, их вывод pass/fail, трассы, ссылки `файл:строка` |
| `cloud-question.md` | `/cloud-escalate` | ОДИН точный вопрос + факты + опровергнутые гипотезы + 1–2 варианта + запреты |
| `decision.md` | человек | Почему выбрано решение и что проверено |

Шаблоны — в `.ai/templates/`. `TASK-ID` — id карточки Notion, имя ветки или backlog-id;
главное, чтобы он был стабильным между сессиями.

## Правила

- **Порядок обязателен.** Эскалация в облако без `brief.md` + `recon.md` + `hypotheses.md`
  + `evidence.md` — преждевременная. Исключение одно: vision/PDF/видео, где локальный
  контур физически не применим.
- **Гипотеза без контрпроверки не считается.** Если нельзя назвать наблюдение, которое её
  опровергнет, это не инженерный вывод, и к реализации он не допускается.
- **Второе мнение засчитывается не по согласию.** `/glm-second-opinion` выполнен, если
  добавлен новый проверяемый факт либо существующая гипотеза укреплена доказательством.
- **Патч только после подтверждения причины.** Если причину можно проверить более дешёвым
  экспериментом — сначала эксперимент.

## Почему папка не в git

`.ai/` целиком в `.gitignore`: в evidence и трассы попадают внутренние URL, фрагменты
конфигов, иногда PII из тестовых данных. Ценность артефактов — в текущей и следующей
сессии; долговременный канон живёт в Notion (открытое) и `docs/plans/DONE.md` (закрытое).
