# HR Helper v2 — корень

Единственный всегда загруженный рул. Остальные подтягиваются по надобности: по `globs`
(когда файл в контексте) или по запросу — список доступных правил с описаниями тебе виден,
запрашивай нужное вместо того, чтобы гадать.

## Стек

NestJS + Prisma (`apps/backend`) · React + Vite + React Query (`apps/frontend`) · gRPC Session
Manager (`apps/telegram-sessions`) · Chrome MV3 (`apps/extension`) · npm workspaces + Turborepo ·
`packages/types|dto|utils|proto|rpc` · Connect RPC (`apps/backend/src/connect/`).

## Лестница моделей — сверху вниз, не наоборот

| Шаг | Кто | Для чего |
|---|---|---|
| 1 | `Qwen 3.6 27B — Architect` | разобрать задачу, найти execution path, риски. Только чтение |
| 2 | `GLM4 Local — Analyst` | независимое второе мнение, контрпримеры. Только чтение |
| 3 | `Qwen3 Coder 30B — Executor` | **единственный с правом менять файлы** и запускать проверки |
| 4 | `Mistral Small 3.2 — Reviewer` | разбор диффа, тестов, контракта. Только чтение |
| 5 | `GLM-4.6 — Cloud Routine` → `GLM-4.7 — Cloud Coder` → `GLM-5 / GLM-5.2 — Cloud Judge` | тупик, которого локальный контур не разрешил |
| 6 | `Gemini 3.6 Flash` | PDF, картинки, видео, UI-скриншоты, контекст сверх локального окна |

Правило перехода: **следующий шаг разрешён только после того, как предыдущий отработал и не
справился**. «Модель звучит неуверенно» — не основание; основание — противоречие между
локальными мнениями, отсутствие причинной связи после экспериментов или высокий blast radius
(auth, RBAC, JWT, refresh token, HMAC/webhook, миграции БД, биллинг, конкурентность, массовое
изменение данных).

## Облако — жёсткие потолки

- **Z.AI идёт через Coding Plan** (`/api/coding/paas/v4`). Pay-as-you-go баланса на ключе нет,
  General API отвечает 429 «Insufficient balance» — туда не ходить. Подписка тратится
  **промптами за окно**, а не токенами: каждый вызов расходует квоту, независимо от размера.
  Лестница внутри плана и что делать на 429 — правило `model-rotation`.
- **Gemini: не чаще 4 вызовов за 2 минуты и 10 за 30 минут.** Считать самому, лимит внешний —
  детали и поведение при `429 RESOURCE_EXHAUSTED` в правиле `gemini-rate-limits`.
- У облачных моделей нет ролей `edit`/`apply` и не будет. Облако возвращает решение,
  аргументацию, риски и проверяемый следующий шаг. Патч применяет только Executor.
- В облако не уходят: секреты, `.env`, токены, дампы БД, PII кандидатов и сотрудников, логи с
  внутренними URL, весь репозиторий и вся история чата «на всякий случай».
- **Никогда сам, даже если инструмент разрешён** (решение владельца 2026-10-30): `git push`,
  `gh pr merge`, ssh/scp на VPS, сетевые запросы наружу (`curl`, `wget`, `fetch_url_content`),
  чтение `.env*` — в том числе `cat`/`head`/`grep` в терминале. Нужно одно из этого — остановись
  и скажи, что и зачем; делает человек.

## Протокол задачи

`/task-brief` → `/local-recon` → `/glm-second-opinion` → `/execute-evidence` → при тупике
`/cloud-escalate`. Артефакты — в `.ai/task/<TASK-ID>/`, по файлу на шаг (см. `.ai/README.md`).
Гипотеза без способа опровержения к реализации не допускается. Второе мнение засчитывается не
по согласию, а по новому проверяемому факту.

## Never

`body: unknown` в контроллере · raw `fetch()` вместо `HttpClientService` · `$transaction(cb)`
без `{timeout, maxWait}` · `findMany` без `take` (max 100) · `async .map()` без `Promise.all` ·
mutable singleton state · `PrismaWriteService` для SELECT · `process.env` вне `config/` ·
`void redis.*` без `.catch` · `refresh_token` в JSON web-ответа · JWT в URL (SSE — только ticket) ·
Swagger UI в production · plaintext API-ключи в конфигах и коде · HMAC через `===` вместо
`timingSafeEqual` · новый агент без `registerQueueAgent()` · `dangerouslySetInnerHTML` без
DOMPurify · `shared/` импортирует из `features/` · файл >500 строк без декомпозиции.

## Always

Новый read-heavy endpoint → Connect RPC, не REST · `PrismaReadService` для SELECT · SSE-auth →
ticket + heartbeat 25s · vite build → `NODE_OPTIONS=--max-old-space-size=6144` · найден
баг/уязвимость → карточкой t-boards в «Ошибки» сразу · перед работой над пунктом бэклога → читать
карточку t-boards (там канон постановки; Notion — архив только для чтения), `docs/plans/archive/FIX.md` и `docs/plans/BACKLOG.md` заморожены ·
закрытие пункта → статус карточки И запись в `docs/plans/done/<модуль>.md` (оглавление — `docs/plans/DONE.md`).

## Инструменты — контракт вызова

Ошибка в имени инструмента не восстанавливается на лету, поэтому контракт живёт здесь, а не в
подгружаемом руле:

- Вызывать только инструменты из текущего списка. Не выдумывать имена инструментов и аргументов.
- Не вызывать shell-команды как инструменты (`cat`, `ls`, `find`, `grep`, `sed`, `awk`, `git`,
  `npm`, `pnpm`, `yarn`, `python`, `bash`).
- Читать файл — только файловым инструментом, с непустым строковым `path`.
- Править существующий файл — точное имя `edit_existing_file`. Инструмента `edit_file` не
  существует, его вызов — всегда ошибка.
- Обязательные аргументы не пропускать. Один вызов за раз, если параллельность не нужна по существу.
- Если ни один доступный инструмент не решает задачу — объяснить ограничение, а не подменять
  shell-командой.

Куда идти за информацией: символы и ссылки на них — MCP `serena` (`find_symbol`,
`find_referencing_symbols`) раньше, чем читать файл целиком; `grep`/`glob` — то, что serena не
понимает (yaml, .env, sql, md); борд — MCP `t-boards` (через хаб); сжатие длинных тредов — `headroom`.

## Definition of Done

1. Назвать изменённые файлы и зачем. 2. Прогнать самый узкий релевантный чек
(`turbo run lint|typecheck|test:run --filter=<pkg>`, не весь `npm run ci`). 3. Сообщить точные
команды и результат pass/fail, не «должно работать». 4. Назвать оставшиеся риски и непроверенные
пути. 5. Миграции, prod-конфиг, auth-флоу, PII-пути — не трогать без явного плана и ревью.
