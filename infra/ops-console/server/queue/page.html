      Отчёты

      Ход работ

      Задачи агентов и ваша очередь — в цифрах и на шкале времени. Агенты обновляют статусы сами. Отставание — дни после плановой даты. План от 15.10 предварительный: это оценка агента, сроки уточняются по мере работы. С 20.10 к строкам плана прикреплены карточки Notion — кнопка «N карточек» в отчёте открывает список.

      Ваша очередь по дням

      Сколько пунктов поставлено вам и сколько вы закрыли к концу каждого дня. Разрыв между линиями — то, что ждёт вас.

      Задачи агентов: план и факт

      Пунктир — сколько задач должно быть готово к дате по плану, сплошная — сколько готово на деле. Если сплошная ниже пунктира, агенты отстают.

      Готовность по разделам

      Карточки Notion в плане

      Сколько карточек «Задач» и «Ошибок» прикреплено к строкам каждого направления и сколько из них уже закрыто («закрыто», «выполненные», «завершённые»).

      Незакрытые карточки Notion (включая «на ревью») в дни сверок — из сводки, которую агенты обновляют при каждой сверке с Notion.

      Отставание от плана, дни

      Сверху — открытые задачи позже плана: их отставание растёт каждый день. Ниже, свёрнуто, — закрытые с опозданием или досрочно, с итоговым сдвигом. Вправо — позже плана, влево — раньше; задачи в срок здесь не показаны.

      Сколько PR ждали мёржа

      Каждая точка — PR: когда открыт и сколько часов прошло до мёржа. Пустой кружок — ещё открыт. Высоко стоящие точки — рассинхрон между готовым кодом и мёржем.

      Диаграмма Ганта (предварительная)

      Рамка — план, заливка — факт, красный хвост — отставание, красная вертикаль — сегодня. Названия задач не прокручиваются вместе с полосами.

      Роадмап по неделям

      Вехи по направлениям: залитый ромб — достигнута, пустой — по плану, с красной обводкой — просрочена.

        Как пользоваться
        1. Решения — нажмите кнопку с нужным вариантом. Этого достаточно: пункт считается решённым, я увижу выбор. Комментарий — по желанию.
        2. Мёржи и ручные проверки — выполните команду или шаги, поставьте галочку «Сделано». Если что-то пошло не так — напишите в поле.
        3. Команды на сервере — подключитесь по ssh (как подключиться), выполните блок, вставьте вывод в поле под ним и поставьте галочку.
        4. Всё сохраняется само, писать мне в чат не нужно. Передумали — «Изменить ответ» под пунктом.
        5. «Ждёт вас снова» — вы уже ответили, но агенту снова нужны вы (вопрос в ответ, вывод с ошибкой, «повторите проверку»): что именно — в строке «Агент» под пунктом. Ответьте ещё раз — пункт закроется.

        Решения

        У каждого пункта — рекомендация. Нажмите кнопку с вариантом.

        Мёржи

        Команды — из корня репозитория. Любой push в main с кодом сразу выкатывает прод (15–25 минут, около 3 минут сайт отвечает 502). Деплои идут по одному: влитые подряд схлопнутся в последний.

        На сервере

        Агентам ssh на прод закрыт. Всё, кроме очистки диска и установки агента, — только чтение. Вывод вставляйте в поле под командой.

        Как подключиться к серверу с вашего Mac

        1. Откройте «Терминал» (⌘ Пробел → «Терминал») или терминал в VS Code.
        2. Выполните ssh root@173.212.238.170 (это тот же сервер, что hrhrm-v2.com). Ключ ~/.ssh/id_ed25519 и его пароль уже сохранены в связке ключей macOS, сервер уже в списке известных — вопросов быть не должно.
        3. Приглашение сменится на root@…:~# — вы на сервере. В пункте ниже нажмите «Копировать», в Терминале — ⌘V и Enter.
        4. Скопируйте вывод: выделите текст мышью и нажмите ⌘C. Для длинного вывода — cat /tmp/hrh-disk-diag.txt (блок диагностики сохраняет вывод в этот файл) или заберите файл на Mac из нового окна Терминала: scp root@173.212.238.170:/tmp/hrh-disk-diag.txt ~/Desktop/. Вставьте вывод в поле под пунктом.
        5. Выйти с сервера: exit.

        Если не пускает: «Permission denied (publickey)» — ключ не загружен, выполните ssh-add --apple-use-keychain ~/.ssh/id_ed25519 (один раз спросит пароль ключа) и повторите шаг 2. «Connection timed out» — проверьте интернет или VPN. «REMOTE HOST IDENTIFICATION HAS CHANGED» — ничего не подтверждайте и напишите мне.

        Для агентов: как добавить пункт владельцу и отметить свою работу

        С 18.10.2026 очередь живёт в ops-консоли (переехала из артефакта claude.ai). Писать — MCP-инструментами oq_* из общего хаба или в API /api/oq/v1/db/<коллекция>/<id> (PUT — заменить, PATCH — дополнить; Authorization: Bearer oq_…). Перед правкой существующего документа прочитать его и передать ifVersion. Ответы владельца сервер агенту менять не даст (403), сдвиг planEnd без basePlanEnd — 409.

        items/<id>  пункт владельцу (id: d-… решение, m-… мёрж, s-… сервер, c-… ручная проверка)
  {kind: 'decision'|'merge'|'server'|'check', title, body, cmd, after, cmd2,
   options: [{id, label, hint}]   // только decision; рекомендуемый первым, hint: 'рекомендую'
   chips: [['деплой','deploy'] | ['ssh','ssh'] | ['после #N','wait'] | ['текст','']],
   links: [{href: 'https://…', text}], added: 'YYYY-MM-DD', source: '<имя сессии>', archived: false}
  body — простой текст: абзацы через пустую строку, строки «- » — список, «1. » — нумерованный.

checks/<id>  ответ владельца {done, choice, note, at} — читать, НЕ менять.
  Свой статус по пункту — update полей {agentStatus: 'taken'|'doing'|'blocked'|'done'|'planned', agentNote}.

work/<id>  задача агента для отчёта, Ганта и роадмапа
  {title, track: 'tails'|'providers'|'council'|'secfront'|'ops'|<id направления из базы>, status, who: 'agent'|'owner',
   session, planStart, planEnd, start, end ('YYYY-MM-DD'), milestone: bool, note, link, linkText, order,
   cards: [{id: '<32 hex страницы Notion>', t: заголовок, k: 'bug'|'task', s: severity|priority, st: статус, c: код}]}
  planEnd не переписывать: от него считается отставание. Сдвиг плана — новый planEnd
  и basePlanEnd = прежняя дата, причина — в note. В строку коллеги — только своё поле (oq_patch, ifVersion).

work/track-<id>  направление «Хода работ» {kind: 'track', name, color: 'var(--c1)'…'var(--c6)', order, archived}
  Пять базовых направлений вшиты в страницу, документ с их id меняет имя и порядок.
  Новое направление без цвета получает общий цвет продуктовых блоков (--c6).

work/notion-stats  сводка сверки с Notion {kind: 'stats', at, bugs: {critical, high, medium, low, none},
  tasks: {P0, P1, P2, P3, none}, inPlan, notInPlan, halfBaked, history: [{d: 'YYYY-MM-DD', bugs, tasks, inPlan}]}
  Пишет агент при сверке с Notion (история — точка на каждый день сверки). У карточки Notion поле «Очередь» =
  id строки плана: по нему видно, что карточка уже в плане; новая карточка без него — кандидат в строку блока.
