# infra/ops-console (`hrh-ops-console`) — роль: инженер ops-консоли (мониторинг · алерты · перезапуск)

**Роль:** владелец отдельной системы наблюдения за продуктом: обзор, инфраструктура (агенты на серверах,
контейнеры, метрики), внешние проверки и TLS, алерты (Telegram / email / webhook с HMAC), инциденты, деплои
(GitHub Actions), события, отчёты ИИ-совету, публичная `/status`. **Не связана с продуктом** ни кодом, ни базой, ни
учётками (решение владельца 2026-10-06), кроме SSO через платформенного администратора (`apps/backend/src/modules/ops-sso`).
Свой `package-lock.json`, вне npm workspaces. Устройство, развёртывание и безопасность — `README.md`.

## Логика решений

- **Перезапуск контейнера — действие с гарантиями:** только через локальный контроллер хоста (`agent/`), с причиной,
  журналом и защитой от повторов; stateful-сервис требует подтверждения вводом его имени.
- **Алерт — сигнал, а не шум:** у правила есть порог, длительность, подавление флапов и понятное «что делать»;
  молчание агента — сам по себе алерт.
- **Доверие к входу:** allowlist хостов, доверенный прокси для IP клиента, CSRF, rate limit; секреты агента — на сервере
  в `/etc/hrh-ops-agent.env`, не в репозитории.
- **Переносимость:** работает локально и без переделки переезжает на бесплатный хостинг (Render/Vercel + libSQL/Turso).

## Команды (в `infra/ops-console`)

`npm ci` · `npm run dev` (API `:8797`, Vite `:5180`) · `npm run build && npm start` · `npm run typecheck` · `npm test`
(сквозной сценарий на временной БД + чистая логика) · `npm run db:migrate`.

## Гейт

`npm run typecheck && npm test`; изменение агента или перезапуска — живая проверка на стенде; прод-подключение
сервера — по `docs/ops/deploy-contabo.md` («Ops-консоль на проде»).

## Адверсариальная проверка — ≥ 3 участника (обязательно)

x ≥ 3 независимых участника; базовые линзы, x по риску и формат результата — корневой `CLAUDE.md` и `.claude/memory/chunks/process/adversarial-review.md`. Линзы роли:

1. **Сигнал** — ложные и пропущенные алерты, флапы, молчание агента.
2. **Нагрузка** — сбор метрик не нагружает прод (частота, объём), консоль укладывается в бесплатный хостинг.
3. **Безопасность действий** — перезапуск, SSO, доверенный прокси, секреты агента.
