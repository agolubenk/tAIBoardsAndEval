## Что не проверено / риски

- Интерполяция `{{names, list}}` / `{{count, number}}` в новых RU-формах проверена только статической сверкой
  плейсхолдеров; рантайм-рендер в браузере не прогонялся (форк локально не поднят — зона Claude).
- `common.appName => Kaneo` оставлен осознанно: переименование бренда — отдельное решение владельца.
- Node v25.9.0 при требовании `^24.11.0 || >=26` — везде WARN про engine, на тесты/линт не влияет.
- Перевод делал один агент без независимого ревью (субагенты были недоступны из-за 429); возможны стилистические
  неоднородности, терминология выровнена по глоссарию из 1961 уже переведённого ключа (рабочая область, задача,
  доска, метка, исполнитель, участник, вежливое «вы»).
