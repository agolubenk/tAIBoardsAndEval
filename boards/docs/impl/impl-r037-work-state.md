# R-037 и хвост K-5 — рабочее состояние сессий на доске, память карточки в MCP

Дата: 29.10.2026. Ветка `t-boards` в `boards`, локальный коммит `6ead678`, пуша нет.

## Решение

R-037: рабочее состояние сессий (шаг, ветка, чего ждёт) переезжает из work_state claude-mem на доску. По Q-023 доска
показывала бы его как вид только для чтения. Но читать work_state из claude-mem доске не из чего:

- HTTP-воркер claude-mem отдаёт work_state только готовым текстом (`GET /api/work-state`, строки вида «ключ=значение»);
- K-5 намеренно не открывает файл базы claude-mem;
- VPS до воркера на Mac не достаёт.

Поэтому состояние хранит сама доска, а агенты пишут его через MCP. claude-mem при этом не меняется (R-040, N-001).

## Что сделано

- **Таблица `session_work_state`** (миграция `0075_t_boards_work_state`, теперь их 76):
  - одна строка на сессию в пространстве; ключ — пространство и актёр (ключ API плюс метка `x-t-boards-session`, как у
    аренд);
  - поля: шаг (≤ 500), ветка (≤ 200), чего ждёт (≤ 500), карточка;
  - строка уходит вместе с карточкой (`cascade`). Сессии, молчащие 30 дней, удаляет следующая запись в пространстве —
    отдельная фоновая задача не нужна.
- **API** `…/forest/{ws}/work-state`:
  - `GET` (`task:read`) — свежие первыми, до 100 строк. Сессия на карточке проекта, который читатель не может открыть,
    скрыта целиком: шаг обычно говорит о самой карточке.
  - `PUT` (`task:update`) — заменяет состояние своей сессии. Карточка проверяется на принадлежность пространству и доступ
    (`assertTaskInWorkspace`).
  - `DELETE` (`task:update`) — убирает свою строку.
- **MCP**:
  - `forest_set_work_state` и `forest_clear_work_state` — у ролей, которые берут аренды (developer, reviewer, planner,
    forester);
  - `forest_list_work_state` и `forest_get_card_memory` (хвост K-5) — у всех ролей, в read-представлении (бюджет, формат);
  - `forestCall` научился отправлять `DELETE`.
- **UI**: вкладка «Сессии» на странице «Лес» — актёр, карточка, проект, шаг, ветка, чего ждёт, время обновления.
  Обновление раз в минуту. Подписи есть во всех 21 локали: в ru-RU по-русски, в остальных английский текст, как у остальных строк леса.
