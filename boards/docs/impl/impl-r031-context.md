# R-031 — контекст-пакет карточки и поиск с выдержками

Готово 28.10. Проверено на локальном стенде (`../tools/mcp-probe-r031.mjs`, счётчик o200k).

## Что сделано

- **API** `GET /api/forest/{workspaceId}/cards/{taskId}/context` (`getForestCardContext`) — одним чтением:
  - задача с метками (до 50) и проектом;
  - поля карточки (R-024);
  - живая аренда: держатель, вид, срок, **без fencing-токена**;
  - ждущие «да» по карточке;
  - связи, видимые вызывающему;
  - последние комментарии (kaneo хранит их в `activity` с `type = comment`);
  - какие поля меняли последние правки — без значений: значения есть в истории карточки.
  - Лимиты — `CONTEXT_LIMITS` (комментарии 20, связи 20, история 10, «да» 10); в `truncated` — разделы, где было больше.
  - Код: `apps/api/src/forest/context/*`, маршрут `forest/routes/context-*.ts`.
- **Доступ.** `assertTaskInWorkspace`: чужое пространство — 404, связь с карточкой чужого пространства не видна.
- **MCP.** Инструмент `forest_get_context` — режим чтения (fields, summary, since, ifNoneMatch, budget, format).
- **Поиск.** `search` в MCP отдаёт описание и текст комментария выдержкой ±80 символов вокруг совпадения
  (`view/excerpt.ts`).
- **Бюджет (R-032).** Раньше бюджет не держался, если длинного текста уже не было. Теперь последний проход убирает
  целые элементы списков. Id и короткие значения не режутся.
- **`since`.** Не изменившийся контейнер (карточка) больше не несёт старое описание.
