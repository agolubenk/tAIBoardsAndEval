# R-090, срез 1 — «Пульс» (что горит, что ждёт вас) и лента агентов

Дата: 29.10.2026. Ветка `t-boards` в `boards`, локальный коммит `8bf6ee4`, пуша нет.

## Решение

R-090 — четыре панели: граф связей, лента агентов, «что горит», ⌘K. Этот срез закрывает две, которые читают уже
существующие данные, без новых таблиц и миграций. Граф связей — отдельный срез: ему нужна своя выборка рёбер и
ленивая отрисовка (кандидат в пилот пайплайна).

- **Лента** = `agent_journal` (R-036) — каждое действие агента и человека на доске уже там, с исходом `allowed`/`denied`.
- **«Что горит»** = открытые баги и срочные карточки. Баг «горит», если его severity начинается с crit / block / high /
  major / p0 / p1 / крит / блок / высок. Severity — свободный текст из Notion и от агентов, поэтому распознаём начало
  слова, а кириллицу пишем обоими регистрами: при C-локали базы `~*` складывает регистр только для ASCII.
- **«Ждёт вас»** = запросы «да» в ожидании плюс сессии, у которых в рабочем состоянии (R-037) заполнено «чего ждёт».
- **Отказы за сутки** — та же лента с фильтром `denied`, на панели только последние 24 часа.

Видимость: запись ленты о карточке или проекте видна, только если читатель может открыть этот проект. Если карточки уже
нет (срублена, удалена), проект не восстановить — такую запись видит только читатель без ограничений по проектам.
Записи о не-карточках (запрос «да», сектор, инструмент MCP) видны всем участникам. Записи MCP без пространства
(`workspaceId` null) в ленту пространства не попадают.

## Что сделано

- **API** (`task:read`, оба — `GET`):
  - `…/forest/{ws}/journal` (`listForestJournal`) — новое сверху, по 30 (до 100), курсор по `(createdAt, id)`.
    Фильтры: `actor=agent|all` (по умолчанию только агенты), `outcome=denied`. К записи приклеены номер, заголовок и
    проект карточки.
  - `…/forest/{ws}/fires` (`listForestFires`) — горящие баги, затем срочные, затем прочие баги; внутри группы — старые
    первыми. Отдаёт `total` по всем и первые 10 (до 100). Не берёт архивные проекты, статус `archived` и финальные
    колонки (`isFinal`).
  - Ловушка: `projectAccessCondition` пропускает NULL-проект, поэтому в ленте рядом стоит `isNotNull(project.id)`.
- **Web**:
  - Вкладка **«Пульс»** — первая и открывается по умолчанию: «Ждёт вас» (до 5, кнопка «Все запросы» ведёт на вкладку
    запросов «да»), «Что горит» (значок пламени, бейджи «Баг: severity» / «Срочно», проект, «открыта … назад»), «Отказано
    за сутки» (кнопка «Открыть ленту»). Каждая секция — со счётчиком и пустым состоянием.
  - Вкладка **«Лента»** — переключатель «Агенты / Все», флажок «Только отказы», «Показать ещё».
  - Обе обновляются раз в минуту (`refetchInterval` 60 с) — новый канал реалтайма не заводил.
- **i18n**: 30 ключей в 21 локали (RU — по-русски, остальные — английский, как у прочих вкладок леса), `schema.json`.
- **OpenAPI**: +345 строк — 2 операции, 2 схемы (`ForestJournal`, `ForestFires`).

Файлы:

  `forest/routes/pulse-schema.ts`, подключение в `forest/index.ts`.
- Web: `fetchers/forest/list-journal.ts`, `list-fires.ts`; `hooks/queries/forest/use-journal.ts`, `use-fires.ts`;
  `components/forest/pulse-{tab,section,waiting,fires,denied}.tsx`, `journal-{tab,row}.tsx`, тесты `pulse-tab.test.tsx`,
  `journal-tab.test.tsx`; `forest-types.ts`, `forest-page.tsx`, маршрут `forest.tsx` (вкладка по умолчанию — `pulse`).
- Тест: `tests/api-integration/forest-pulse.test.ts`.
