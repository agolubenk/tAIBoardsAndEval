### Схема доступа — А (принято владельцем 28.10)

**А.** Публичная A-запись остаётся, она нужна только для сертификата.
- Сертификат: `certbot certonly --webroot -d d4dev.admin.hrhelper.space`. ACME на `:80` уже отвечает для любого имени.
- Сервер t-boards в nginx слушает только WG-адрес VPS.
- Mac резолвит имя в WG-адрес через `/etc/hosts` или DNS туннеля.
- Снаружи t-boards не отвечает. Публичный `:443` отдаёт сертификат продукта, как сейчас.
- Новых токенов не нужно.

**Б.** A-запись указывает на WG-адрес, сертификат через DNS-01.
- Нужен токен Cloudflare файлом и образ certbot с плагином `dns-cloudflare`.
- Чище: публичное имя никуда не ведёт. Но настраивать дольше.
