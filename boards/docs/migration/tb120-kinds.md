## Виды и правило переноса

| Вид | Откуда | Подвид | Определение при переносе |
|---|---|---|---|
| Задача | «Задачи» | feature · refactor · spike · bugfix | Task Type → подвид; пусто → feature |
| Ошибка | «Ошибки» | баг · алерт · инцидент · уязвимость | дефолт **баг**; уточняется при разборе (П5) |
| Идея | «Задачи», Task Type = idea | — | сырая: агент не берёт без «да» (как half-baked) |
| Перманентная | в Notion типа нет | проверка · период · фокус · принято | заводится после перехода — см. `tb120-permanent.md` |

«Банк идей» остаётся проектом (решение `d-tb-kinds`), вид «идея» — свойство карточки.

## Оформление по видам (шаблон карточки)

Общее для всех: 8 колонок процесса владельца (Новая → Прожарка → Открыта → В работе → На ревью →
Подтверждение → Готово · Закрыта), проект по Module (`tb120-projects.md`), метки Module/Tags, Backlog ID /
Bug ID, Report-ссылка, Half-baked idea (блокирует аренду), Est.

- **Задача**: постановка (что/зачем/приёмка), подвид (Task Type), Priority, Est. Поля агента: исполнитель,
  ветка, PR, токены.
- **Ошибка**: что сломалось и где (файл/строка), шаги воспроизведения, ожидание/факт, **серьёзность**
  (Severity → шкала карточки), подвид (дефолт баг). Метка «Ошибка» на доске (решение 30.10: ошибка — вид
  карточки, не проект).
- **Алерт** (подвид): что монитор сработал и порог; ссылка на источник сигнала; действие по умолчанию.
- **Инцидент** (подвид): время/окно воздействия, что задето, статус-лента, причина и урок.
- **Уязвимость** (подвид): поверхность, оценка, путь эксплуатации — только владельцу, без публичных деталей.
- **Идея**: гипотеза и ценность, что проверить; без Est/Priority; агент не берёт без «да» владельца.
- **Перманентная**: категория (проверка/период/фокус/принято), расписание/триггер, дата пересмотра — поля
  после П1 (`tb120-permanent.md`).
