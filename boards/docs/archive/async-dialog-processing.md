# Асинхронный диалог-процессор (Async Dialog Processor)

## Концепция

Асинхронный диалог-процессор — это система, которая позволяет обрабатывать задачи асинхронно, используя "стикеры" для отслеживания состояния задач. Это позволяет сессиям переключаться между задачами, не теряя прогресс.

### Ключевые идеи:

1.  **Стикеры (Stickers)**: Уникальные метки, которые прикрепляются к задачам для отслеживания их статуса.
2.  **Асинхронная обработка**: Задачи обрабатываются в фоновом режиме, позволяя основной сессии продолжать работу.
3.  **Сохранение состояния**: Состояние задачи сохраняется, даже если сессия переключается или завершается.
4.  **Группировка задач**: Задачи могут быть объединены в группы для совместной обработки.
