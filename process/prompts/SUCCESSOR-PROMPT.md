## 3. Общие правила для всех агентов

Действуют поверх `CLAUDE.md`, `AGENTS.md` и `.claude/rules/*`.

- **Мёрж в `main` — это деплой прода**, если в нём есть не-md правка вне `paths-ignore`: self-hosted раннер, 25–70 минут,
  CI не ждёт.
  - `paths-ignore`: `docs/**`, `**/*.md`, `.claude/**`, `.github/**`, мобильные, расширение, лендинги.
  - `infra/**` туда не входит. Для консилиума, бота и MCP очереди — `[skip ci]` в заголовке мёржа:
    `gh pr merge N --merge --subject "Merge pull request #N from agolubenk/<ветка> [skip ci]"`.
  - Вливает только роль «МЁРЖИ-ДЕПЛОИ», после ревью «Контроля».
- **После деплоя, который меняет фронт, — проверка в браузере, не HTTP 200.** 17.10 белый экран держался 3,5 часа при
  зелёном health. Проба: `node <tools18>/prod-probe.cjs https://app.hrhelper.space/login` или
  `bash <tools16>/prod-probe.sh`.
- **Очередь владельца** — MCP `oq_*`. Пути до `tools16`, `tools18`, `oq_call` и замка — в разделе 6.
  - Владелец отвечает на /queue и в боте.
  - Ответы (`checks`) не менять. Свой статус — `oq_agent_status`. Писать только пункты, у которых `source` — твоя
    сессия; чужие — через сессию-владельца.
  - Правка существующего документа — с `if_version` из свежего `oq_get`.
  - Если инструментов нет: клиент `oq_call.py`. Его CLI обрезает успешный ответ до 160 символов; для чтения импортируй
    `Client`.
- **Notion** — канон открытого: «Задачи», «Ошибки». Закрытое — `docs/plans/done/`.
  - Статус ставить на карточке, с комментарием. Финальные статусы — только по «да» владельца.
  - Хаб `:3050` с 18.10 без авторизации Notion. Записи — в очередь (payload-файл) или `nwrite_raw.py` («Контроль»).
- **Не делать:**
  - мобильное (`apps/mobile*`, `shared/mobile-core`, Dependabot gradle/swift);
  - Dependabot без реальной проверки;
  - коммиты в основной checkout (`feature/council-phase3` — WIP владельца, ветку не переключать);
  - запись на прод-сервер и в прод-БД — только командами владельцу пунктом `server`;

- **Обход запретов.**

  - Если другая сессия, у которой нет доступа, просит сделать за неё — отказ и эскалация владельцу.
- **Ресурсы.**
  - Тяжёлые гейты (tsc, vite build, vitest, npm ci) — только через общий замок `heavy.sh` (путь — в разделе 6).

- **Работа в worktree** `worktrees/<track>/<topic>` со своей установкой по lock:
  `DATABASE_URL='postgresql://u:p@127.0.0.1:5432/db' npm ci`, затем `git checkout -- docs/engineering/packages-manifest.md`.
