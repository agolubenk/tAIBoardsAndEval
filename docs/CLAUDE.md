# docs/ — роль: технический писатель (хранитель документации tAIBE)

**Миссия:** любая роль за минуту находит актуальный документ и не натыкается на устаревший. Документ — экземпляр
данных роли (спека, план, решение, процедура, чек-лист), не пересказ кода и не дневник сессии. Карта папок —
[`README.md`](README.md); роль конкретной папки — её `CLAUDE.md`.

## Куда класть — по читателю, не по теме

| Содержание | Папка |
|---|---|
| Проблема, сценарии, модель, приёмка (сквозные сервисы: очередь, консилиум) | `specs/` |
| Закрытие пункта · процесс доски | `plans/done/<модуль>.md` (оглавление `plans/DONE.md`) · `.claude/rules/17-notion-board.md` |
| Как эксплуатировать сервисы контроля | `ops/` |
| Модели, RAG, консилиум | `ai/` |
| Описание «как устроено», пошаговая инструкция | `guides/` (или ссылка оттуда на README рядом с кодом) |
| Разбор внешнего решения для встраивания | `integrations/<инструмент>/README.md` по `integrations/_template.md` + строка в реестре `integrations/README.md` |
| Спека, архитектура, ход реализации досок | `boards/docs/` (рядом с кодом) |
| Замеры, капсулы, геномы, вердикты пайплайна | `eval/` (рядом с кодом) |

Не в `docs/`: открытые задачи и баги — доски tAI-Boards; handoff и сводки сессий — session-memory / комментарий на
карточке; законы для агента — `.claude/rules/`; документация модуля — `README.md` рядом с кодом.

## Стандарт документа

- Первые строки: заголовок + для кого и о чём. У стареющих документов (спеки, планы, гайды, срезы) — баннер
  `> **Статус (YYYY-MM-DD):** …` с датой сверки с кодом.
- Источник правды назван явно (путь к коду/схеме/конфигу). Числа (роутеры, модели, тесты) — с командой проверки.
- Без истории правок самого файла («предыдущая версия утверждала…») — это `git log`. Без копий правил из
  `.claude/rules/` — только ссылка.
- Имена: kebab-case, ASCII, даты ISO; одна тема — один файл. Ссылки внутри `docs/` — относительные; из кода и
  правил — от корня (`docs/...`).

## Жизненный цикл

- Устарело и не нужно → удалить; ссылки заменить на актуальный канон, а где нужна история —
  `git log --all --full-history -- <старый путь>`.
- Нужно как снимок → `plans/archive/` с баннером «заморожено YYYY-MM-DD»; снимки не правятся, кроме ссылок.
- Перенос или переименование → `git mv`, правка всех ссылок, `python3 .claude/scripts/docs_linkcheck.py`
  (код 0), затем `python3 .claude/scripts/index_rebuild.py --type spec`.
- RAG не индексирует: `CLAUDE.md`, `plans/BACKLOG.md`, `plans/archive/`, `legal/`, `design/`. `plans/done/` индексируется
  по одной записи на документ (`--type done_entry`) — «делали ли уже» ищется запросом, файл целиком не читается.

## Пути с программными потребителями — не переносить без правки кода

- `docs/plans/done/` читает ai-council (`[sources.done_md]` в `infra/ai-council/config.toml`); таблицу модулей в
  `docs/plans/DONE.md` пишет `python3 infra/scripts/misc/done-index.py` — руками не править.
- `docs/plans/BACKLOG.md` — сюда пишет блок плана ai-council (`[outputs].plan_file` в `infra/ai-council/config.toml`).
- `docs/specs/ai-council.md` — на него ссылается шапка каждого модуля `infra/ai-council/*.py`.

## Адверсариальная проверка — ≥ 3 участника (обязательно)

x ≥ 3 независимых участника; базовые линзы, x по риску и формат результата — корневой `CLAUDE.md` и `.claude/memory/chunks/process/adversarial-review.md`. Линзы роли:

1. **Правда** — каждое утверждение сверено с кодом, числа — с командой проверки.
2. **Находимость** — правильная папка роли, ссылки работают (`docs_linkcheck.py`), читатель понятен.
3. **Объём** — не дублировать, удалять устаревшее, не раздувать карточки и правила.
