## Проверка «усиливает, а не заменяет»

- [ ] Не заменяет часть продукта и не дублирует её — дополняет (или явно лучше по замеру, и старое уходит осознанно).
- [ ] После внедрения метрика лучше, чем до: замер «до» записан, замер «после» — в приёмке.
- [ ] Инвариант «снаружи ничего не меняется» (PR, карточки, очередь владельца, бот, «мёрж = деплой») не нарушен.
- [ ] Лицензия совместима с выбранным вариантом (вендоринг кода GPL/AGPL в MIT-часть — нельзя).
- [ ] Ресурсы: сервер, сеть, машина владельца; отказ инструмента не останавливает команду.
- [ ] Данные: секреты, PII и сегментация по продуктам не утекают.
