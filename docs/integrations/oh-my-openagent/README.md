## Что это

- **Назначение.** «OmO» — свой агентный harness с мультимодельной оркестрацией (`README.md`, `oh-my-openagent/docs/guide/overview.md`).
  Три редакции: **OmO Native** — команда `omo` на **senpi**, форке [pi](https://github.com/badlogic/pi-mono)
  (`README.md`, «Install»); **OpenCode-плагин** (`packages/omo-opencode`, «legacy»,
  `oh-my-openagent/docs/guide/migrating-from-opencode.md`); **адаптер Codex** (`packages/omo-codex`, «Vendored Codex plugin namespace»).
  Редакции для Claude Code нет: `packages/claude-code-compat-core` лишь **читает** конфиги Claude Code
  (`.claude/skills|agents|commands`, `.mcp.json`, хуки `settings.json`) внутри своего harness
  (`oh-my-openagent/docs/reference/features.md`, «Claude Code Compatibility»).
- **Ядро.** TypeScript/Bun-монорепо (~474K строк TS без тестов в `packages/`) + Rust-крейты computer use (`crates/`).
  Главный агент делегирует через `task` по **категориям** (`quick`, `deep-low/high`, `ultrabrain`, `writing`…) — у
  каждой цепочка моделей с откатом (`oh-my-openagent/docs/reference/features.md`, «Category System», «Current Agent Model Chains»);
  read-only агенты `explore`, `librarian`, `plan-consultant`, `plan-reviewer`; фоновые агенты; Team Mode (эксперимент,
  выключен) — до 8 участников, общий почтовый ящик, задачи с файловыми замками.
- **Хуки** — 58 слотов в 5 ярусах (`oh-my-openagent/docs/reference/features.md`, «Hooks»): `rules-injector` (`.claude/rules/` по
  globs), `preemptive-compaction`, `tool-output-truncator` (урезает вывод grep/glob/LSP по окну контекста),
  `comment-checker` (блок «AI-slop» комментариев), `write-existing-file-guard`, `runtime-fallback` (смена модели на
  429/5xx), `todo-continuation-enforcer`.
- **Память «Kibitzer»** (`oh-my-openagent/docs/guide/orchestration.md:79–81`, `packages/memory-core`): git-репозиторий markdown-заметок
  + резидентная дешёвая sidecar-сессия на каждую главную. Получает ограниченные, замаскированные события (промпты,
  вызовы, головы результатов), тратит ход модели только когда всплывает ещё не оценённая заметка, ≤ 8 read-only
  вызовов на пробуждение, ≤ 2 пробуждений на машину, единственный выход — подсказка `recalled memory: <hint>`.
- **Прочее:** hash-anchored `edit` (`LINE#ID`, xxhash32, отказ при устаревшем хэше; `packages/hashline-core`, по
  умолчанию выключен), «ожидание сборки — подписка, не опрос», запись проверенного для рестарта
  (`packages/boulder-state`), скрипты `check-test-junk.ts` и `mutation-proof.ts` («тест теста», `CHANGELOG.md` 5.1.55).
- **Принцип, который стоит процитировать** (`oh-my-openagent/docs/reference/features.md`, «Instruction Files vs Enforcement»):
  `AGENTS.md` — контекст, а не граница прав; детерминированное — только конфиг прав, allowlist инструментов, хуки.
- **Зрелость/темп.** 390 тегов (`git ls-remote --tags`); два релиза за 2026-11-01 (5.1.55 и 5.1.56, `CHANGELOG.md`).
  Звёзды, число контрибьюторов — **не проверено** (GitHub API из сессии недоступен).
- **Телеметрия включена по умолчанию** — PostHog (США): версии, модели, токены и стоимость на ход и на задачу,
  использованные фичи; без промптов и кода (`oh-my-openagent/docs/guide/telemetry.md`). `/bug` отправляет транскрипт сессии (`README.md`).
- **Лицензия — Sustainable Use License 1.0** (`LICENSE.md`; source-available, не OSI): использование и модификация
  «только для собственных внутренних бизнес-целей или некоммерчески», распространение — только бесплатно и
  некоммерчески, лицензия «non-sublicensable, non-transferable». Вклад — по CLA с правом владельца перелицензировать
  (`CLA.md`).

## На что ложится в tAIBE

- **Harness — нет.** Основной harness tAIBE — Claude Code (`claude --settings` геномов П1, хуки `.claude/hooks/`);
  зеркала `.continue/`, `.agents/skills/` — только скиллы для других клиентов (`.claude/scripts/sync-agent-skills.sh`).
  Ни senpi/pi, ни OpenCode tAIBE не использует (grep по репо: упоминания OpenCode — лишь как потребитель
  `.agents/skills/`). Внедрение OmO = смена harness, а это замена слоя, не дополнение.
- **PIPELINE §9 прямо исключает** «универсальный оркестратор» и «второй MCP-шлюз» (`eval/pipeline/PIPELINE.md`) — OmO
  и есть универсальный оркестратор со своими MCP (`websearch`, `context7`, `grep_app`, `lsp`).
- **Где идеи пересекаются с нашими механизмами:**
  - Категории с цепочками моделей ↔ геномы ролей П1 + `infra/llm-gateway` (ротация ключей/моделей) + рой П9 на Haiku.
  - Kibitzer ↔ «иммунная память» П2, DAMS-чанки по ключевым словам (`.claude/hooks/user-prompt-submit.py`),
    claude-mem. Разница: у нас подмешивание детерминированное и бесплатное, у них — дешёвая модель-судья.
  - boulder-state / запись проверенного ↔ капсула П6 (`card_meta.context_pack`) и `work_state` леса.
  - «подписка, не опрос» ↔ Нерв П7–П10 и подписки на PR (`docs/plans/evolution-ideas.md` §4).
  - `tool-output-truncator` ↔ хвосты `результат:Bash/Read` (П9: $93.5 + $20.7 в Т2).
  - `check-test-junk` / `mutation-proof` ↔ вопрос 24 `evolution-ideas.md` §5 (мутационное тестирование).

## Риски и открытые вопросы

- **Привязка к harness.** OmO живёт только в senpi/OpenCode/Codex; Claude Code — лишь источник конфигов для
  compat-слоя. Любой путь, кроме идей, = миграция с Claude Code, на котором стоят геномы, капсулы и Нерв.
- **Лицензия SUL-1.0 + CLA с перелицензированием** — условия может поменять владелец; tAIBE — MIT-продукт, его
  распространение с кодом OmO не допускается.
- **Подписки Anthropic в стороннем клиенте.** README: «Anthropic subscriptions, all covered», `/login` для Claude;
  `CHANGELOG.md` 5.1.55: установщик раньше переписывал версию Claude Code, которую движок «объявлял» в OAuth-запросах к
  Anthropic (путь удалён в senpi#5131). Соответствие условиям Anthropic для подписки владельца — **не проверено**; риск
  для учётной записи — повод не подключать.
- **Утечки.** Телеметрия по умолчанию включена (PostHog, США; токены и стоимость на ход); `/bug` — транскрипт;
  встроенные удалённые MCP (`websearch`, `context7`, `grep_app`). Для кода HR_Helper-v2 — новый получатель данных
  (инвариант 5, решение d5 только для роя).
- **Темп изменений** (два релиза в день) — любые заимствованные ссылки на их поведение быстро устаревают; фиксировать
  коммит, как здесь.
- Открыто: позволяет ли Claude Code хуку PostToolUse заменять вывод встроенных Grep/Bash (для идеи 2) — проверить по
  документации Claude Code с датой; окупается ли Kibitzer-подобный sidecar против бесплатного DAMS-подмешивания —
  только пилотом.

## Вердикт и рекомендация

**Брать идею (A), инструмент не брать.** Почему: это не дополнение, а альтернативный harness (senpi/OpenCode/Codex),
tAIBE на нём не работает; PIPELINE §9 исключает универсальный оркестратор; SUL-1.0 запрещает вендоринг в MIT-части;
телеметрия по умолчанию и вход по подписке Anthropic из стороннего клиента — риски данных и учётной записи. Самое
ценное — принцип «инструкция ≠ граница прав» (каждое Never → хук/deny с тестом) и дизайн «sidecar просыпается только
на совпадение памяти, ≤ 8 read-only вызовов, выход — одна строка» как кандидат для П2/П9. Атрибуция при внедрении идеи —
в доке хука/правила и в корневом `README.md` (Origins).

Карточка tAI-Boards — не заведена (доски недоступны из этой сессии), завести «Идеи из oh-my-openagent: enforcement
правил и sidecar-память». Адверсариальная проверка консилиумом (≥ 3 линзы) — **не проведена**; предварительные
возражения автора: корректность — sidecar-подсказки могут уводить «не туда» (вопрос 6 §5); ресурсы — каждое
пробуждение — Haiku-токены, окупаемость не доказана; продукт/простота — (1) и (2) дешёвые и детерминированные, (3)
брать только после (1)–(2).
