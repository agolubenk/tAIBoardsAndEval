# HR Domain Skills

## Vacancy Statuses
- Open, In Progress, Closed, Cancelled
- Status transitions: Open → In Progress → Closed/Cancelled
- Workflow rules for status changes

## Candidate Entities
- Personal data (PII handling)
- Application tracking
- Interview stages and evaluations
- Assessment scores and feedback

## PII Rules
- All personal data must be encrypted at rest
- Access to PII requires explicit authorization
- Data retention policies enforced
- GDPR compliance requirements

## Integration Patterns
- Telegram integration for notifications
- Huntflow API integration
- Email service integration
- Calendar API integration
