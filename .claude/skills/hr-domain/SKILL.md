# HR domain

- Read the relevant domain entities and status transitions before proposing changes.
- Do not invent PII retention or access policies; find and cite the actual project policy.
- Treat candidate data as sensitive by default.
- Before designing a feature area described as "not built yet" (docs, backlog snapshot, even the task brief), check the git history of its module and its models in `schema.prisma` — documentation lags the repository in both directions.
